# Introduction to Programming with Python

Like any language, there are two parts to using a computer language. First, you
have to learn practical details of the language: its vocabulary, grammar and
syntax. Then, you have to learn how to express more and more complex ideas
using these basic components.

In this workshop, you will write Python programs that solve a few problems. As you solve these problems, you will also have to think about what makes good, clear code.


## Your task

In this repository you will find a number of exercises. You should prepare solutions to the problems given and commit your solutions to this repository. You may work in groups and produce the solutions as a group; just ensure that you comment, where appropriate, who is responsible for which portions of code. For the last two exercises you may find this approach preferable.


## What are we looking for?

We will be looking for:
1. how well your solution works;
1. how effectively your code's structure helps clearly express its logic; and
1. how effectively your code's style helps its readability.

Ideally, we should be able to clone your own repo and run your code with no issues. Remember that we will be also looking at how well you structure and present your
solution. It's better to submit a partial solution that is
clearly structured and stylishly written, rather than to submit a full solution
that is poorly structured and badly written!


## Other Notes:

* In our workshops we have been using Jupyter Notebooks, but for these exercises
  you should create pure Python scripts. That is, your solution to each
  problem should consist of a .py file which you can run by typing, for
  example, `python exercise1.py`.
  
* A notebook with brief summaries of each task description is also provided. Use this to proto-type your code before turning your solutions into Python scripts.
